# Warworld · 战争世界

一部完全离线的 2D 中世纪大战略游戏。无需安装、无需构建、无需联网：直接用浏览器打开 `index.html` 即可开始。

## 运行

- 推荐 Chrome / Edge / Firefox 的较新版本。
- 直接双击 `index.html`，或把整个文件夹拖进浏览器。
- 存档使用浏览器 LocalStorage；换浏览器、清理站点数据会丢失存档。

## 主要系统

- **世界**：程序化大陆、森林、丘陵、湖泊、河流、高山、矿脉与资源点；可选三档地图尺寸与 1–7 个 AI 对手。
- **聚落**：村庄 → 小镇 → 城市 → 首都。资源按聚落独立储存，仓库提高上限，商队负责运输。
- **经济**：木材、食物、石材、铁矿、金矿、银矿、草药、皮革、铁、金、银、银币。采石场可能挖出矿脉；浆果采集可能得到草药；猎人提供皮革。
- **建造**：资源建筑、民宅、市场、酒馆、教堂、诊所、医院、码头、兵营、靶场、马厩、城墙、城门、箭塔、骑士团、桥梁、隧道与道路。施工需要居民/建筑工。
- **内政**：人口上限、粮食与木材消耗、稳定度、独立风险、救助金、聚落改名、开拓新聚落。
- **军事**：民兵/远程/骑兵/禁军/圣骑士，船只运载，单位自动索敌，手动攻城，箭塔自动射击，城墙阻挡与城门开闭。
- **外交**：好感、贸易商队、同盟、盟友求援、附庸、宗主征召、边界冲突/征服/独立/无端战争等战争理由、停战与停战协定。
- **科技**：图书馆 → 大学 → 皇家大学，三级科技树，需要学者进驻并消耗资源。
- **AI**：会经营经济、建造、研究、扩张、结盟、贸易、附庸与开战；难度越高发展越快，开局备战期越短。

## 操作

| 输入 | 功能 |
| --- | --- |
| 左键 / 拖框 | 选择单位或建筑 |
| 右键 | 移动、采集、施工、进入建筑、攻击 |
| 中键拖动 | 平移地图 |
| 滚轮 | 缩放 |
| 方向键 | 平移地图 |
| `Space` | 暂停 / 继续 |
| `1` / `2` / `3` | 0.5× / 1× / 2× |
| `B` | 建造面板 |
| `I` / `D` / `T` / `M` | 内政 / 外交 / 科技 / 军事 |
| `H` / `C` | 王国法典 / 编年史 |
| `F` | 回到首都 |
| `G` | 选择全部空闲居民/建筑工 |
| `Esc` | 关闭当前面板 / 取消选择 / 暂停菜单 |
| `Ctrl+S` | 立即保存 |

## 测试

游戏本身没有运行依赖。开发期使用无头浏览器（Puppeteer）做回归测试；测试脚本、截图与 `node_modules/` 不会提交到仓库。游玩时无需 Node.js。

## 说明

- 游戏刻意采用较慢的节奏：默认 1 天 = 7 秒，1 年 = 360 天。可以随时暂停或调整速度。
- 普通难度下，AI 在开局约 110 天内不会主动向你宣战，留出建设与备战时间；简单/困难/传奇分别约为 180/70/45 天。
- 所有美术、音乐与音效均由 Canvas 与 Web Audio 实时生成，不包含外部素材。
