# 战争世界 · Warworld

> **Demo 0.3 · 公开测试版** — 本作仍在开发与测试中，玩法、数值和界面会继续调整，可能存在 Bug 或存档兼容性问题。欢迎通过 [Issues](https://github.com/dawnskingofSDH/warworld/issues) 反馈问题与建议。

## 0.3 更新摘要

- **高分屏适配**：界面以 1600×900 为基准，整体随窗口分辨率缩放（1920 约 1.2×、2560 约 1.6×、4K 约 2×），文字、按钮与面板同步放大；地图上的定居点、单位与放置提示也会一起缩放。
- **名称与界面**：主菜单、浏览器标题统一为「战争世界」；左上角突出当前定居点名称，阵营名移到副行；连续出现的相同提示合并为「×N」，外交操作提示不再被面板遮挡。
- **性能与地图**：优化缩小地图时的渲染卡顿；地图尺寸与定居点领地范围进一步扩大；铁矿、金矿、银矿等稀有矿脉的出现概率降低。
- **人口与民宅**：民宅产生居民的速度放缓，且每座民宅独立计时，不再整排同时添丁；每个定居点的民宅数量受阶段上限约束（村庄 4 / 小镇 8 / 城市 12 / 首都 16），升级大厅可提高上限。
- **建造与经济**：伐木场与采石场不再消耗石材；建筑升级费用约为同级新建的 60%；建造面板可选择当前阶段已解锁的任意等级；己方建筑与资源点均可拆除 / 清除。
- **系统修复**：市政厅升级不再卡在银币；内政界面「建立新的定居点」恢复可用；单位可遣散以释放人口；选中居民清除资源点不再丢失选择；稳定度降至 0 立即独立；贸易协定期限可调（20–120 天），已签订协定可在外交界面查看。

## 运行

- 推荐 Chrome / Edge / Firefox 的较新版本。
- 直接双击 `index.html`，或把整个文件夹拖进浏览器。
- 界面会按窗口分辨率自动缩放；高分屏若仍觉得偏小，可再用浏览器缩放微调。
- 存档使用浏览器 LocalStorage；换浏览器、清理站点数据会丢失存档。

## 主要系统

- **世界**：程序化大陆、森林、丘陵、湖泊、河流、高山、矿脉与资源点；可选三档更大的地图尺寸（200×150 / 280×205 / 380×270）与 1–7 个 AI 对手。定居点领地范围也随大厅等级扩大。
- **聚落**：村庄 → 小镇 → 城市 → 首都。资源按聚落独立储存，仓库提高上限，商队负责运输；可从内政界面开拓新聚落。
- **经济**：木材、食物、石材、铁矿、金矿、银矿、草药、皮革、铁、金、银、银币。铁矿脉、银矿脉与金矿脉较为稀少；采石场可能挖出微量矿脉；浆果采集可能得到草药；猎人提供皮革。升级到市政厅不再需要尚未解锁的银币。
- **建造**：资源建筑、民宅、市场、酒馆、教堂、诊所、医院、码头、兵营、靶场、马厩、城墙、城门、箭塔、骑士团、桥梁、隧道与道路。施工需要居民/建筑工。建造面板可选择当前阶段已解锁的建造等级，而非只能造最高级；伐木场与采石场只消耗木材；每座定居点的民宅数量随阶段提高上限（4/8/12/16）；升级现有建筑只需同级新建费用的约 60%。己方建筑可在详情页拆除（大厅除外），拆除不返还资源，但会安置好内部人员。
- **内政**：人口上限、粮食与木材消耗、稳定度、独立风险、救助金、聚落改名、开拓新聚落。稳定度低于 25 时每天有独立风险，降至 0 会立即独立。
- **军事**：民兵/远程/骑兵/禁军/圣骑士，船只运载，单位自动索敌，手动攻城，箭塔自动射击，城墙阻挡与城门开闭。任何单位都可以遣散，以腾出人口。
- **外交**：好感、贸易商队（可设置 20–120 天交付期限）、同盟、盟友求援、附庸、宗主征召、边界冲突/征服/独立/无端战争等战争理由、停战与停战协定。已签订的贸易协定可在外交界面查看。
- **科技**：图书馆 → 大学 → 皇家大学，三级科技树，需要学者进驻并消耗资源。
- **AI**：会经营经济、建造、研究、扩张、结盟、贸易、附庸与开战；难度越高发展越快，开局备战期越短。

## 操作

| 输入 | 功能 |
| --- | --- |
| 左键 / 拖框 | 选择单位或建筑 |
| 右键 | 移动、采集、施工、进入建筑、攻击 |
| 中键拖动 | 平移地图 |
| 滚轮 | 缩放 |
| 方向键 | 平移地图 |
| `Space` | 暂停 / 继续 |
| `1` / `2` / `3` | 0.5× / 1× / 2× |
| `B` | 建造面板 |
| `I` / `D` / `T` / `M` | 内政 / 外交 / 科技 / 军事 |
| `H` / `C` | 王国法典 / 编年史 |
| `F` | 回到首都 |
| `G` | 选择全部空闲居民/建筑工 |
| `Esc` | 关闭当前面板 / 取消选择 / 暂停菜单 |
| `Ctrl+S` | 立即保存 |

## 说明

- 游戏刻意采用较慢的节奏：默认 1 天 = 7 秒，1 年 = 360 天。可以随时暂停或调整速度。
- 普通难度下，AI 在开局约 110 天内不会主动向你宣战，留出建设与备战时间；简单/困难/传奇分别约为 180/70/45 天。
- 所有美术、音乐与音效均由 Canvas 与 Web Audio 实时生成，不包含外部素材。
- 当前为 Demo 0.3，功能和数值仍可能调整；后续版本可能修改存档格式，测试期存档不保证长期兼容。
